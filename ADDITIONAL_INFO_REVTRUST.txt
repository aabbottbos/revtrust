🎯 Strategic Analysis: Data Collection & Enhanced Insights

Current State Summary

What You're Doing Well:

Strong technical foundation for deal analysis and business rule
violations
AI-powered risk scoring and coaching infrastructure
Flexible data model with JSON fields for extensibility
Win/loss pattern detection capabilities
Team forecast rollup features
Critical Gap Identified:
RevTrust operates in a "context vacuum" - your AI coaches without knowing:

WHO the user is (hunter vs farmer, experience level, methodology)
WHAT they sell (product complexity, deal structure, typical cycles)
WHERE they operate (territory, market dynamics, competition)
WHY deals matter differently (strategic accounts, quota pressure,
timing)
📊 Proposed Data Collection Framework

I recommend a three-tier approach to data collection:

TIER 1: Critical Context (Onboarding - Must Have)

Captured during first-time setup, blocks progress until complete

TIER 2: Enhanced Context (Progressive Disclosure)

Captured naturally during product usage via smart prompts

TIER 3: Advanced Context (Power User Features)

Opt-in for users wanting maximum personalization

🎯 TIER 1: Critical Context Data Points

Revenue Targets & Quota Management
Why: Foundation for all forecast coaching and gap analysis

Data to Capture:

Annual quota/target ($)
Quarterly breakdown (Q1-Q4 targets)
Achievement percentage vs quota (optional historical)
Target setting authority (self-set, manager-assigned, company-mandated)
How to Capture:

Onboarding step: "What's your revenue target for [current quarter]?"
Allow easy updates in Settings → Performance tab
For teams: Manager sets team targets, optionally individual targets
AI Enhancement Unlocked:

✅ Accurate gap-to-quota coaching
✅ "You need 3 more deals like X to hit quota"
✅ Prioritization based on quota urgency
✅ Week-by-week pacing recommendations
Implementation Priority: 🔴 HIGH - Forecast coaching requires this

Sales Methodology Preference
Why: Coaching should align with how they actually sell

Data to Capture:

Primary methodology: MEDDIC, BANT, Sandler, Solution Selling,
Challenger, Custom, None
Optional: Specific framework elements they track (e.g., "We always
identify Economic Buyer")
How to Capture:

Onboarding: "How does your team qualify deals?" (dropdown + description)
Settings → Profile tab for changes
AI Enhancement Unlocked:

✅ Coaching aligned to methodology (e.g., MEDDIC: "Have you identified
the Decision Criteria?")
✅ Risk factors based on missing methodology elements
✅ Next best actions match their sales process
✅ Win/loss analysis by methodology adherence
Implementation Priority: 🔴 HIGH - Dramatically improves coaching
relevance

Role & Selling Profile
Why: Hunters and farmers need completely different coaching

Data to Capture:

Primary role: Individual Contributor (AE/SDR), Manager, Director/VP,
C-Level
Selling motion: Hunter (new logos), Farmer (account management), Hybrid
Years in sales: <1, 1-3, 3-5, 5-10, 10+
Team size (if manager): number of direct reports
How to Capture:

Onboarding: "Tell us about your role" (3 quick questions)
Auto-detect from CRM if possible (owner name patterns, deal types)
AI Enhancement Unlocked:

✅ Hunter: Aggressive prospecting coaching, urgency on early-stage deals
✅ Farmer: Expansion coaching, churn risk alerts, relationship depth
✅ Junior reps: More educational coaching, sales process reinforcement
✅ Senior reps: Strategic coaching, deal complexity navigation
✅ Managers: Team-level insights, coaching team members on risky deals
Implementation Priority: 🔴 HIGH - Fundamentally changes coaching tone

Typical Sales Cycle & Deal Profile
Why: Context for "is this deal moving too slow?"

Data to Capture:

Average sales cycle length (days or range: <30, 30-60, 60-90, 90-180,
180+)
Typical deal size (range: <$10K, $10K-$50K, $50K-$100K, $100K-$500K,
$500K+)
Deal count per quarter (1-5, 5-10, 10-25, 25-50, 50+)
Sales model: Transactional, Mid-market, Enterprise
How to Capture:

Onboarding: "Describe your typical deal" (3 dropdowns)
Auto-calculate from historical data after first analysis
AI Enhancement Unlocked:

✅ Accurate "deal velocity" risk scoring
✅ "This deal is 2x your average cycle - high risk"
✅ Stage duration benchmarks customized to user
✅ Deal prioritization by realistic close timing
Implementation Priority: 🟡 MEDIUM-HIGH - Improves risk scoring accuracy

🎨 Feature Recommendations: How to Capture & Use This Data

Feature 1: Smart Onboarding Flow

What: 3-step onboarding wizard on first login

Steps:

About You (30 seconds)
- Role dropdown
- Hunter/Farmer/Hybrid selector
- Years in sales slider
Your Sales Process (45 seconds)
- Methodology dropdown with descriptions
- Typical cycle + deal size
- Team size (if manager)
Set Your Target (30 seconds)
- Current quarter revenue target
- Optional: Annual target for auto-quarterly breakdown
- "Skip for now" option (but persistent reminder)
Why This Works:

Gets critical context immediately
~2 minutes total (low friction)
Can skip and complete later
Unlocks personalized coaching instantly
Implementation:

New users redirected to /onboarding on first visit
Progress saved (can complete across sessions)
Completion badge/reward
Reminder banner if skipped
Feature 2: Dynamic Settings Enhancement

What: Expand Settings page with new tabs

New Tabs:

Profile - Role, methodology, experience, selling motion
Performance - Targets/quota by quarter, update anytime
Territory - Market, industry, geography, competition
Products - Product catalog, typical cycles, pricing
Preferences - Coaching style, notifications, tone
Why This Works:

All context editable in one place
Progressive disclosure - only show what's relevant
Non-blocking - can update anytime
Import/export for bulk operations

Dismissible but persistent

💡 Key Success Factors

Start Small, Learn Fast
- Phase 1 captures 80% of value with 20% of effort
- Test onboarding conversion rates before building more
Make It Optional (But Valuable)
- Never block core features
- Show value immediately when context is added
- "Before/after" examples of coaching quality
Progressive Disclosure
- Don't ask for everything upfront
- Prompt when relevant
- Celebrate completion milestones
Auto-Detection When Possible
- Infer methodology from deal patterns
- Calculate benchmarks from historical data
- Pre-fill from CRM data
Show, Don't Tell
- Demo better coaching in onboarding
- Real examples: "Coaching without context" vs "With context"
- Quick wins (set target → see gap instantly)
